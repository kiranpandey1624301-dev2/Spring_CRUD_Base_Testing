# Spring Boot CRUD Base Testing

## Overview
This project demonstrates CRUD operations using Spring Boot and REST APIs.

## Technologies Used
- Java
- Spring Boot
- Spring Data / JDBC (as implemented in the project)
- Gradle
- REST API

## Features
- Create student records
- Retrieve student records
- Update student records
- Delete student records

## Project Structure
- `controller` – Handles REST API requests
- `service` – Contains business logic
- `dao` – Data access operations
- `model` – Student model class

## How to Run
1. Clone or download this repository.
2. Open the project in Eclipse or another Java IDE.
3. Configure the database in `application.properties`, if required.
4. Run `SpringCrudProjectApplication.java`.

## Learning Objectives
- Understand the layered architecture of a Spring Boot application.
- Learn how REST APIs interact with controller, service, and DAO layers.
- Practice CRUD operations.
